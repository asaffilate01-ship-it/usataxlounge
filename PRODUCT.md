# TaxCenda: PRODUCT.md

US taxpayers and tax/accounting professionals conducting evidence-based reviews and filing approvals use this platform for secure receipt and tax evidence, client questions, duplicates, fixed assets, accountant review, final filing package and approvals.

Existing visual language: Current src/index.css uses ink-navy HSL 222 54% 20% primary, teal HSL 172 78% 41% accents, Inter and Playfair; dark mode separately defined.

Important UX and trust rules: Filing approval, taxpayer identity, consent, uploaded evidence, AI extraction confidence, unresolved duplicate records and authority to transmit must be explicit. Never claim a return is filed because a screen is green; only verified provider response counts.

Only audited code and verified backend outcomes substantiate status, fees, availability or compliance. Human-controlled approval points cannot be bypassed by design work.
