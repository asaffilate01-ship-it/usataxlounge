# Public marketing claims requiring verification before release
This list is a content gate, not proof that services or credentials exist. Do not republish a claim from an old page just because it has a translation or image.

| Claim present in previous site content | Before public use |
| --- | --- |
| 5,000+ returns filed, 98% retention, $20M+ tax savings, 20+ years' experience | Signed, dated, reproducible business evidence and approved definitions. First-wave redesigned components removed these counters. |
| Six named five-star testimonials | Independently authenticated quotations and permission from each named client; otherwise do not display. First-wave redesign removes them. |
| IRS-authorised Enrolled Agents, access to all 50 states, worldwide representation | Verify named professionals' active credential/registration, eligibility, geographic scope and actual availability. Avoid implying IRS endorses the company. |
| Full IRS e-file authorisation, filed returns, IRS accepted status | Current provider EFIN/MeF authorisation and a verified provider receipt/acceptance event for each specific return. No hypothetical transition or default counter. |
| Bank-level encryption and 'secure & compliant' | Engineering evidence: encryption configuration, storage privacy, MFA, access control tests, incident response and a written security plan. |
| Guaranteed refunds, maximised refunds, tax savings | Clear estimates and conditional wording; statutory outcomes depend on facts and official determinations. |
| Physical Miami address and 24-hour responses | Verified contact address and published, staffed response SLA; otherwise display no invented physical address/timing. |
| iTechLounge LLC is trading-name owner | Verify US entity, legal name, marketing authority and consumer terms before public launch. |

Priorities: attorney/EA/CPA credential verification; PTIN/EFIN where relevant; taxpayer data security; scope-specific Form 8879/e-sign validation; IRS/FinCEN filing-event provenance. US and non-resident workflows must follow applicable current-year rules. Any claim restored to marketing requires a recorded owner, dated source and expiry review.

Do not expose real client tax documents to a public design skill, prompt, MCP server or automated UX testing tool. Use synthetic staging fixtures.
